### Task 2: The SITL port-bind flake — diagnostics, capture on CI, root cause

Spec §4 (W1). **What planning established** (2026-10-13; keep it in mind, do not re-derive it):

- **CI:** two failures today, both "Betaflight SITL could not bind its ports", both on **the first SITL launch of a
  fresh process** shortly after another process's SITL session ended: run 38437153244 (tag `v0.1.0`), the wheel
  step's `test_sitl_sandbox.py`, 16 s after the same test passed in the step before; run 38440416805 (`main`
  95227fd), `crates/ofs-sim/tests/sitl_live.rs`'s first test (`a_betaflight_reboot_is_a_firmware_restart_not_a_crash`,
  at `Rig::new`'s `build()`), right after ofs-fc's `sitl_live` binary finished. The run in between (38433946652)
  passed. So on CI it is frequent — two of three runs.
- **Local (WSL):** six cycles of CI's exact sequence (the live pytest list, then the sandbox test in a fresh process)
  — no failure, no SITL or `ofs-sim` left alive afterwards. Fifteen rounds of `pkill` + an immediate relaunch — no
  failure. Betaflight's TCP listeners set `SO_REUSEADDR` (dyad), so `TIME_WAIT` is not it.
- **Not a symptom:** the failing tails are full of `[FLASH_ProgramWord]` lines, but every first boot after a diff is
  applied writes the EEPROM once (between the UART2/3/5 binds and the UART1/4 binds) — checked locally.
- **The evidence is lost by our own logging:** SITL prints its bind lines on stderr and everything else on stdout;
  two reader threads interleave them, and the 200-line tail fills with ~1 000 flash lines, so neither failure shows
  *which* port failed, nor does anything say who held it.
- **A real defect found on the way:** `apply_diff` (`crates/ofs-fc/src/sitl/process.rs:250`) ignores the config
  run's exit status and only checks that `eeprom.bin` exists — but SITL creates `eeprom.bin` at boot, so a config
  run that failed (`[CONFIG] prepareSave failed`, exit 1, or a crash) passes, and the session flies Betaflight's
  defaults without the quad's diff.
- **Why not just `PR_SET_PDEATHSIG`:** it fires when the *spawning thread* exits, and `Load` runs on tokio's
  `spawn_blocking` pool, whose idle threads exit after ~10 s — set naively, it would kill SITL mid-session.
- The default cleanup (`pkill -x betaflight_SITL`) runs before every launch on Linux, so a plain orphaned SITL should
  already be killed before a new one starts. Something in that picture is wrong on CI; the diagnostics will say what.

/// The port of a `bind port 5762 for UART2 failed!!` line.
fn bound_port(line: &str) -> Option<u16> {
    line.split("bind port ").nth(1)?.split_whitespace().next()?.parse().ok()
}

/// Every TCP socket bound to `port`, with its state, and for a listener the process that owns it (pid, command,
/// state, parent pid, working directory): what a bind failure needs to say who holds the port. Linux only (read
/// from /proc); empty elsewhere, and under WSL from Windows (SITL's sockets live in the WSL VM).
#[cfg(target_os = "linux")]
pub fn port_holders(port: u16) -> Vec<String> {
    const STATES: [&str; 12] =
        ["?", "ESTABLISHED", "SYN_SENT", "SYN_RECV", "FIN_WAIT1", "FIN_WAIT2", "TIME_WAIT", "CLOSE", "CLOSE_WAIT", "LAST_ACK", "LISTEN", "CLOSING"];
    let mut sockets = Vec::new(); // (state, inode)
    for table in ["/proc/net/tcp", "/proc/net/tcp6"] {
        let Ok(text) = std::fs::read_to_string(table) else { continue };
        for line in text.lines().skip(1) {
            let f: Vec<&str> = line.split_whitespace().collect();
            let local = f.get(1).and_then(|a| a.rsplit(':').next()).and_then(|p| u16::from_str_radix(p, 16).ok());
            if f.len() > 9 && local == Some(port) {
                let state = usize::from_str_radix(f[3], 16).ok().and_then(|s| STATES.get(s)).copied().unwrap_or("?");
                sockets.push((state, f[9].to_string()));
            }
        }
    }
    let mut out = Vec::new();
    for (state, inode) in sockets {
        let mut owner = String::new();
        if state == "LISTEN" {
            let target = format!("socket:[{inode}]");
            for p in std::fs::read_dir("/proc").into_iter().flatten().flatten() {
                let pid = p.file_name().to_string_lossy().to_string();
                if !pid.bytes().all(|b| b.is_ascii_digit()) {
                    continue;
                }
                let Ok(fds) = std::fs::read_dir(p.path().join("fd")) else { continue };
                if fds.flatten().any(|fd| std::fs::read_link(fd.path()).is_ok_and(|l| l.to_string_lossy() == target)) {
                    let comm = std::fs::read_to_string(p.path().join("comm")).unwrap_or_default();
                    let stat = std::fs::read_to_string(p.path().join("stat")).unwrap_or_default();
                    let mut rest = stat.rsplit_once(')').map_or("", |(_, s)| s).split_whitespace();
                    let (pstate, ppid) = (rest.next().unwrap_or("?"), rest.next().unwrap_or("?"));
                    let cwd = std::fs::read_link(p.path().join("cwd")).map(|c| c.display().to_string()).unwrap_or_default();
                    owner = format!(" by pid {pid} ({}, state {pstate}, parent {ppid}, cwd {cwd})", comm.trim());
                    break;
                }
            }
        }
        out.push(format!("{state}{owner}"));
    }
    out
}

}

/// Starts a child that cannot outlive the simulator. Linux: `PR_SET_PDEATHSIG` kills SITL when its parent dies —
/// but "parent" means the *thread* that forked it, and `Load` runs on tokio's blocking pool, whose idle threads
/// exit. So every SITL is forked from one thread that lives as long as the process.
#[cfg(target_os = "linux")]
fn spawn_child(cmd: Command) -> std::io::Result<Child> {
    spawner::spawn(cmd)
}

#[cfg(not(target_os = "linux"))]
fn spawn_child(mut cmd: Command) -> std::io::Result<Child> {
    cmd.spawn()
}

#[cfg(target_os = "linux")]
mod spawner {
    use std::process::{Child, Command};
    use std::sync::mpsc::{channel, Sender};
    use std::sync::{Mutex, OnceLock};

    type Request = (Command, Sender<std::io::Result<Child>>);
    static SPAWNER: OnceLock<Mutex<Sender<Request>>> = OnceLock::new();

    pub fn spawn(mut cmd: Command) -> std::io::Result<Child> {
        use std::os::unix::process::CommandExt;
        // SAFETY: prctl is async-signal-safe, which is all a pre_exec hook may call.
        unsafe {
            cmd.pre_exec(|| {
                if libc::prctl(libc::PR_SET_PDEATHSIG, libc::SIGKILL) != 0 {
                    return Err(std::io::Error::last_os_error());
                }
                Ok(())
            });
        }
        let gone = || std::io::Error::other("the SITL spawner thread is gone");
        let tx = SPAWNER.get_or_init(|| {
            let (tx, rx) = channel::<Request>();
            std::thread::Builder::new()
                .name("ofs-sitl-spawner".into())
                .spawn(move || {
                    for (mut cmd, reply) in rx {
                        let _ = reply.send(cmd.spawn());
                    }
                })
                .expect("failed to start the SITL spawner thread");
            Mutex::new(tx)
        });
        let (reply_tx, reply_rx) = channel();
        tx.lock().unwrap_or_else(|e| e.into_inner()).send((cmd, reply_tx)).map_err(|_| gone())?;
        reply_rx.recv().map_err(|_| gone())?
    }
}

def reply_payload(buf, cmd):
    """The payload of the first complete `$M>` reply to `cmd` in `buf`, or None while it has not fully arrived.

    A reply is `$M>`, a size byte, the command, the payload and a checksum; a TCP read can end anywhere in it."""
    i = buf.find(b"$M>")
    while i != -1:
        if len(buf) < i + 5:
            return None
        size, got = buf[i + 3], buf[i + 4]
        end = i + 6 + size
        if len(buf) < end:
            return None
        if got == cmd:
            return buf[i + 5:end - 1]
        i = buf.find(b"$M>", end)
    return None

    """Parent spec §1.4: Configurator changes take effect and persist. Its PID tab sends MSP_SET_PID then
    MSP_EEPROM_WRITE on this port; the new value must read back at once, after the reboot a Save triggers, and in a
    new session of the same quad (its firmware directory keeps eeprom.bin)."""
    sim.load(QUAD, seed=1)
    sim.run(4.0)
    msp = Msp(sim)
    try:
        before = msp.request(MSP_PID)
        assert len(before) == 15, before  # roll, pitch, yaw, level, mag: P, I, D each
        changed = bytearray(before)

    state = sim.run(1.0)
    for _ in range(30):  # Betaflight reboots (about 1.6 s of real time), the simulator relaunches it

    finally:

```python
#!/usr/bin/env python3
"""The real-time factor of headless runs (parent spec §8.6: the target is >= 2x real time on a mid-range PC).

    python scripts/benchmark.py [--binary PATH] [--seconds 30] [--summary] [--floor X]

For each configuration: load the shipped quad in lockstep, warm up 1 simulated second, then time `run(seconds)` on
the wall clock; the real-time factor is simulated seconds / wall seconds. The Betaflight rows need OFS_SITL_LAUNCH
and are skipped without it. `--summary` appends the table to $GITHUB_STEP_SUMMARY; `--floor X` exits 1 when a
measured row is below X (CI uses 1: shared runners are noisy, so the floor catches regressions, not the target).
Run it from the repository root (the quad path is relative to it).
"""
import argparse
import os
import sys
import tempfile
import time
from dataclasses import dataclass

QUAD = "quads/opendrone-5f-freestyle.toml"
# (name, load() arguments, sticks during the run, needs Betaflight)
CONFIGS = [
    ("open loop, recording", {"open_loop_fc": True, "record": True}, {"throttle": 0.5}, False),
    ("open loop, no recording", {"open_loop_fc": True, "record": False}, {"throttle": 0.5}, False),
    ("Betaflight SITL, recording", {"record": True}, {}, True),
    ("Betaflight SITL, no recording", {"record": False}, {}, True),
]


@dataclass
class Row:
    name: str
    simulated_s: float
    wall_s: float | None  # None: skipped
    note: str

    @property
    def rtf(self) -> float | None:
        return None if self.wall_s is None else self.simulated_s / self.wall_s


def table(rows: list[Row]) -> str:
    lines = ["| Configuration | Simulated (s) | Wall (s) | Real-time factor |", "|---|---|---|---|"]
    for r in rows:
        if r.wall_s is None:
            lines.append(f"| {r.name} | {r.simulated_s:.1f} | – | skipped: {r.note} |")
        else:
            lines.append(f"| {r.name} | {r.simulated_s:.1f} | {r.wall_s:.2f} | {r.rtf:.1f}× |")
    return "\n".join(lines)


def below_floor(rows: list[Row], floor: float) -> list[Row]:
    return [r for r in rows if r.rtf is not None and r.rtf < floor]


def measure(sim, seconds: float, load: dict, sticks: dict) -> float:
    """Loads, warms up 1 simulated second, and returns the wall seconds `run(seconds)` took."""
    sim.load(QUAD, seed=1, mode="lockstep", **load)
    if sticks:
        sim.set_sticks(**sticks)
    sim.run(1.0)
    start = time.perf_counter()
    sim.run(seconds)
    return time.perf_counter() - start


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--binary", help="the ofs-sim to measure (default: OFS_SIM_BIN or ofs-sim on PATH)")
    parser.add_argument("--seconds", type=float, default=30.0)
    parser.add_argument("--summary", action="store_true", help="append the table to $GITHUB_STEP_SUMMARY")
    parser.add_argument("--floor", type=float, help="exit 1 if a measured row is below this real-time factor")
    args = parser.parse_args(argv)

    import ofs

    rows = []
    with tempfile.TemporaryDirectory() as data_dir:
        sim = ofs.launch(binary=args.binary, data_dir=data_dir)
        try:
            for name, load, sticks, needs_sitl in CONFIGS:
                if needs_sitl and not os.environ.get("OFS_SITL_LAUNCH"):
                    rows.append(Row(name, args.seconds, None, "OFS_SITL_LAUNCH not set"))
                    continue
                rows.append(Row(name, args.seconds, measure(sim, args.seconds, load, sticks), ""))
        finally:
            sim.close()
    text = table(rows)
    print(text)
    if args.summary and os.environ.get("GITHUB_STEP_SUMMARY"):
        with open(os.environ["GITHUB_STEP_SUMMARY"], "a", encoding="utf-8") as f:
            f.write("### Real-time factor (parent spec §8.6)\n\n" + text + "\n")
    if args.floor is not None:
        slow = below_floor(rows, args.floor)
        for r in slow:
            print(f"below the floor of {args.floor}×: {r.name} at {r.rtf:.2f}×", file=sys.stderr)
        return 1 if slow else 0
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## Known limitations of v1

### Physics (`docs/research/collision.md`)
- No rotor gyroscopic coupling; friction is viscous below 5 cm/s; `body.accel_ned` is coordinate acceleration (it
  includes gravity); a motor's published `omega_dot` is the derivative before clamping.
- Two contact mechanisms, one per job: hits get impulses, resting weight gets the spring-dampers, so a hard
  touchdown both bounces and compresses the legs. Position correction moves only the deepest contact out.
- The ground is the plane d = 0, boxes are axis-aligned, and objects never collide with each other.
- Vibration is rigid-body and below resonance; on an open-loop build with mixed motor pole pairs the rate
  disturbance ignores gyroscopic coupling.

### Electrical
- The battery is one Thevenin pack: a weak cell is an offset on it, with no per-cell model and no capacity fade.
- ESC and VTX temperatures are a constant 25 °C (the KISS telemetry frames, Tramp's status).
- A dead motor freewheels through its prop's drag only.

### Radio (`docs/research/elrs-link.md`)
- One frequency (2440 MHz) stands for the whole hop sequence; the body shadow is the video link's smooth lobe, not
  a measured 2.4 GHz pattern; the handset transmits on the antenna it receives best on.
- Telemetry slots are a fixed 1:4 ratio of the downlink (`TELEMETRY_SLOT_DIVISOR`), and the shared RC/telemetry
  UART has no contention model.
- The `RadioLoss` fault acts on the uplink only.
- Every constant is an estimate or a published figure; none is measured.

### Video (`docs/research/video-link.md`)
- One knife edge per object, losses of several objects added; reflections off the ground only, and the reflected
  ray is not obstructed separately; one body-shadow lobe of up to 8 dB.
- The receiver's thresholds are named constants, not world-file fields; every constant is an estimate.
- The DVR stops when the picture's size changes mid-recording, and it records what the pilot sees (no clean feed).

- One SITL per machine: its ports are fixed (UDP 9001–9004, TCP 5760+).

- A session whose scheduler failed is poisoned by design; a new `Load` starts a fresh one.
- A Blackbox log of a session that ends armed is cut short: disarm first.

## Rulings worth remembering
These explain behaviour that would otherwise look like a bug.

- **The VTX transmits in open loop**: a powered VTX transmits whether or not a flight controller talks to it.
- **Obstruction is found by a golden-section search** on the shape's signed distance, so a thin post on a long path
  is not stepped over; objects standing on the ground are rooted below it.
- **Emitters may be 5300–6000 MHz** (Lowband is one of the VTX's own bands).
- **The sync-loss test is at 4 km and 25 mW**: at 2 km the shipped diversity goggles sit at the edge.
- **Prop spheres are 2.0 cm**, not 1.5: the larger radius keeps a 12 cm post from passing between them.
- **`collision_speed_mps` is the last collision's speed**: a rebound over 1 m/s raises a second event.
- **A link that starts down raises no `LINK_DOWN`**: the event marks an up-to-down transition.
- **The motor protocol stays PWM**; **the FC telemetry is outside the lockstep digest** (determinism is pinned by
  the ELRS byte-stream test and the live runs); **battery values pass through Betaflight verbatim**, including its
  ESC-sensor consumption summed over motor slots and its 0.1 V units.
- **A stale SITL binary is refused loudly but harmlessly**: it prints one `no such open UART` line per datagram.
- **SITL quads need uniform motor pole pairs** (one `motor_poles` setting), and the diff's `motor_poles` must equal
  2 × `pole_pairs` (checked at load); rotor inertia is per motor.
- **Fault randomness has its own stream** (`elrs-faults`): a fault changes only loss decisions, never the model's
  own draws.
- **The failsafe decode reads Betaflight's arming-disable flags** (RX_FAILSAFE, FAILSAFE), not the BOXFAILSAFE
  mode bit, which a real RX loss never sets.
- **`fault.battery.weak_cell` carries the cell index + 1** (0 means none).
- **The video interference cache is keyed on frequency and the injected emitter**.
- **Records are JSON objects** (`{"v"}`, `{"x","y","z"}`, `{"w","x","y","z"}`) with a JSON schema per shape:
  Foxglove's message paths need object roots.
- **MCAP message indexes stay on**: Foxglove's reader needs them, though they are most of a file's size.
- **A record is stamped with the time after its tick**, `(tick + 1) / base_hz`: what `GetState` reports then.
- **Scheduled faults and inputs apply right after the step that reaches their time**.
- **Inputs rows are relative to the `PlayInputs` call**; columns a file leaves out hold their value; the last row
  holds after playback; the CSV travels in the request (the server reads no client paths).
- **Requests up to 64 MiB**; **sticks have one owner** (a playing file and `SetSticks` exclude each other).
- **Python records lockstep sessions by default**, and `sim.log` only ever returns this session's recording.
- **A world name** (`world="flat"`) is `<quad dir>/../worlds/<name>.toml`.
- **The Blackbox copy runs last** as a session ends (it is the `Session` field declared last).
- **A launched server stops exactly once**: at `close()`, when its `Sim` is collected, or at interpreter exit.

# Architecture

How Open FPV Sim fits together, for contributors. The design and its reasons are in
`docs/superpowers/specs/2026-10-04-open-fpv-sim-design.md`; the models' equations are in `docs/research/`.

## The shape
A headless server, `ofs-sim`, owns the clock and every model. Clients talk to it over gRPC
(`proto/ofs/v1/sim.proto`): the Python package `ofs` for scripts and tests, and the Godot game through a Rust
extension. Betaflight runs as SITL, a separate process the server launches and steps in lockstep over UDP.

## The crates (`crates/`)
| Crate | What it is | Depends on (ofs-*) |
|---|---|---|
| `ofs-core` | The typed signal bus, the `Model` trait, the scheduler, byte wires, constants and seeded RNG streams. Deterministic, no I/O. | — |
| `ofs-config` | Quad, world and part files (TOML): parsing and validation that reports every problem at once. | core |
| `ofs-physics` | 6-DOF rigid body, propellers, impulse collisions with the world. | core |
| `ofs-electrical` | Battery, ESC and brushless motor. | core |
| `ofs-sensors` | IMU and barometer. | core |
| `ofs-rf` | Shared RF: propagation, Rician fading, receiver diversity, body shadow. | core |
| `ofs-radio` | CRSF framing and the ExpressLRS link. | core, rf |
| `ofs-fc` | The Betaflight SITL bridge (process, UDP exchange, UART taps), MSP, and an open-loop stand-in. | core |
| `ofs-video` | The SmartAudio and Tramp VTX, Betaflight's OSD over MSP DisplayPort, the 5.8 GHz analog link. | core, config, fc, rf |
| `ofs-log` | Recording the bus to MCAP (a model appended last that only reads). | core |
| `ofs-proto` | The gRPC messages and stubs, generated from `proto/ofs/v1/sim.proto`. | — |
| `ofs-sim` | The server: vehicle assembly (`vehicle.rs`), sessions, real-time pacing, the gRPC service. | all of the above |
| `ofs-client` | The Rust client: a worker thread, the FPV composite, the DVR muxer. | core, proto |
| `ofs-godot` | The Godot extension (`OfsClient`), a thin layer over `ofs-client`. | client |

## One tick
The scheduler runs at the quad's base rate (8 kHz for the shipped quads). Each model declares a rate divisor and
runs in a fixed order, reading and writing named signals on the bus (`ofs-core/src/names.rs`). Bytes between
models — the receiver's CRSF into Betaflight's UART, Betaflight's OSD out of its UART — travel on bounded `Wire`s.
The SITL bridge is one model: on its ticks it sends the sensor state and UART bytes in one datagram and waits for
Betaflight's motor outputs, so Betaflight advances exactly as far as the simulation (lockstep). In real-time mode a
pacer runs the same scheduler against the wall clock. Randomness comes from named streams derived from the seed
(`ofs-core/src/rng.rs`), so two runs with the same seed and inputs are bit-identical.

## Clients
- **Python (`python/ofs/`):** `ofs.launch()` starts a server and connects; `Sim` wraps the RPCs (load, run, sticks,
  faults, recording, inputs). `ofs.reader` reads recordings, `ofs.rerun` streams a live view.
- **Godot (`godot/`):** `scripts/app.gd` drives the game; `OfsClient` (from `ofs-godot`) runs the client's worker
  and hands GDScript the pose, telemetry, OSD and the delayed FPV composite; `ui/` holds the OSD, HUD, video and DVR.

## How to add…
- **A part** (a motor, prop, battery…): a TOML in `library/<kind>/` named for its id, with `[provenance]` for every
  parameter (`library/README.md`). A new *kind* also needs its struct in `crates/ofs-config/src/part.rs` and its
  resolution in `crates/ofs-config/src/lib.rs`.
- **A model:** implement `ofs_core::Model` in the crate it belongs to, register its signals' names in
  `crates/ofs-core/src/names.rs`, and add it to the assembly in `crates/ofs-sim/src/vehicle.rs` (the order there
  is the run order). Unit-test it against analytic results in the crate's `tests/`.
- **A fault:** a `Fault` variant and its validation in `crates/ofs-sim/src/vehicle.rs`, the bus signals the model
  reads (`fault.*` in `names.rs`), the message in `proto/ofs/v1/sim.proto` (bump the protocol version) and its
  mapping in `crates/ofs-sim/src/server.rs`, and the Python class in `python/ofs/faults.py`. Document it in
  `docs/research/faults.md`.
- **A recorded signal:** any signal on the bus is recordable by name; its default rate comes from the first matching
  pattern in `ofs_log::DEFAULT_RATES` (`crates/ofs-log/src/spec.rs`).
