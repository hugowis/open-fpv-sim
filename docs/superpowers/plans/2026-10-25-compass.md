# The compass: implementation plan (#31)

Spec: `docs/superpowers/specs/2026-10-25-compass-design.md`. Test first at each step, one commit per task. Gates at the end:
`cargo test --workspace --locked --no-fail-fast`, `cargo clippy --workspace --all-targets --locked -- -D warnings`,
`python -m pytest python/tests`. No Godot/protocol change, so no Godot run unless the workspace shows a golden moved
(none should). No `cargo fmt`.

1. **World field** (`ofs-config/src/world.rs`, test in the world tests): three `[environment]` fields with SITL-matching
   defaults and validation.
2. **Maths and model** (`ofs-sensors/src/mag.rs`, tests `crates/ofs-sensors/tests/mag.rs`): `earth_field_ned`,
   `magnetic_heading`, `true_heading`; then `MagParams` + `Mag` (signal names in `ofs-core`), rate divisor, noise, hard/soft iron.
3. **Part + quad config** (`ofs-config`): `MagSection`, `MagPart`, `load_mag`, `mag` in the quad file (schema 7, optional),
   `PartRefs.mag`, provenance order, validation, `library/magnetometers/opendrone-mag.toml`.
4. **Wiring** (`ofs-sim/src/vehicle.rs`): build `Mag` when the quad has one, earth field from the world. Test: signals
   exist and the heading tracks the initial yaw; shipped quads register none.
5. **Docs**: README, `library/README.md`, `docs/research/component-library.md` ledger section,
   `docs/research/sitl-interface.md`, `docs/architecture.md`, `docs/roadmap.md`, CHANGELOG Unreleased.
6. **Gates**, final commit.
