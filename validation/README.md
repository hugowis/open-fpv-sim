# Validation data

Community measurements and the reports that compare them with the simulator. The format, the tool and how to
contribute are in [`docs/validation.md`](../docs/validation.md).

- `thrust-stand/example-2207-5in/` is a **synthetic** worked example (labelled `estimated`, not a measurement) with the
  report `ofs-validate` prints for it.

Data in this folder is under CC-BY-SA-4.0, like the component library.
